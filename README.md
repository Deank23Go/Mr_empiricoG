# Sistema de Gestión de Mantenimiento (Java 21)

Este proyecto está configurado para usar **Java 21 (LTS)** y Gradle 8.5,
lo cual es la opción recomendada por Spring Boot 3.3.x.

## Requisitos
- JDK 21 instalado (`java -version` debe mostrar 21.x).
- PostgreSQL 17 instalado y configurado.

## Comandos
- Compilar: `./gradlew build`
- Ejecutar: `./gradlew bootRun`
